# Academy in a Box — document builders

Editable Word templates each academy fills in to make its own. Everything here
is built from `builders/_helpers.js` so the whole toolkit looks like one family.

## Build

```
npm i docx
node builders/make-placeholders.js            # only after editing the shot list
node builders/build-parent-welcome-pack.js [outPath]
node builders/build-player-welcome-pack.js [outPath]
```

Default output is `~/Downloads/<Name>-TEMPLATE.docx`. Render a PDF proof with:

```
/Applications/LibreOffice.app/Contents/MacOS/soffice \
  -env:UserInstallation=file:///tmp/lo_prof_pk \
  --headless --convert-to pdf --outdir ~/Downloads ~/Downloads/Parent-Welcome-Pack-TEMPLATE.docx
```

(The `-env:UserInstallation` flag is required — the packaged Python wrappers in
the docx/pptx skills need Python 3.10+ and fail on this machine's 3.9.)

## How the templates stay editable

Five deliberate mechanics, in `_helpers.js`:

1. **Placeholder chips.** `pr()` splits any string on `[SQUARE BRACKETS]` and
   styles each one. How loud depends on context (`mark`):
   `chip` yellow highlight inside prose · `quiet` blue inside tables and owner
   guidance · `gold` on the navy cover · `none` in footers. One convention,
   never eye-watering.
2. **Guidance vs fill-in.** `guidance()` renders owner-only instructions as grey
   italic behind a gold rule, visually distinct from words to swap. Academies
   delete guidance; they replace chips.
3. **A find-and-replace index.** Each pack opens with a "Make This Pack Your
   Own" section: step 1 is a table of every repeating placeholder with a blank
   column to write the answer in; the last step is a checklist ending in
   "delete this whole section before you send it".
4. **Photo drop-zones.** `photo()` / `photoRow()` embed real PNGs generated by
   `make-placeholders.js`, not bordered table boxes — so in Word the academy
   right-clicks -> Change Picture and their shot lands in the same frame at the
   same size. Step 3 of the setup section is a **shot list**: every photo slot,
   what to shoot, and what makes it work, plus a consent rule.
5. **A brand page.** Step 2 pairs a logo drop-zone with `swatchTable()` — the
   current navy/gold/tint swatches beside blank cells for the academy's own hex
   codes — and a font table, with Format Painter instructions.

## Pagination

Sections are one-per-page via `sectionDivider`. Three parent-pack sections hold
more than an A4 page, so they split deliberately at a sub-heading using
`h2Page()` rather than dribbling three lines onto an empty page. `h2`/`h3` carry
`keepNext` and table rows `cantSplit`. After any content change, re-render to
PDF and check no page is left near-empty.

## Re-theming

Change `theme` at the top of `_helpers.js` (navy `ink`, gold `accent`) and
rebuild. Nothing else references a colour directly.
