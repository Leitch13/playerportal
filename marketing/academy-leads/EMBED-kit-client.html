Put your funnel on your website.

Two ways to drop the trial funnel onto your site — copy, paste, done. It resizes itself to fit and every lead still flows into your tracker automatically.

Pick one

Two ways to add it

Recommended

A — Embed with a link (iframe)

Host the funnel once to get a web link, then paste a small snippet. Works on any website, resizes itself, and updating the funnel updates it everywhere. Best for Squarespace, WordPress, or any site.

No hosting

B — Paste the whole page

Paste the entire funnel file straight into a Wix or WordPress HTML box. No hosting needed — but to update it you re-paste. Fine if you just want it live fast.

Method A

1. Get a link for your funnel

Your funnel file needs to live at a web address before you can embed it. Easiest free option:

  • Go to app.netlify.com/drop and drag your trial-funnel-matcher.html file onto the page. It gives you a link instantly (rename to index.html first for a tidy URL).
  • Or upload it to your own web hosting, Vercel, or GitHub Pages.

Copy that link — you'll paste it into the snippet below.

2. Paste this embed snippet

Swap REPLACE_WITH_YOUR_FUNNEL_URL for your link. This also makes the funnel auto-resize so there's no scrollbar or empty gap.

Embed snippet
<!-- Trial funnel -->
<iframe id="ppFunnel"
        src="REPLACE_WITH_YOUR_FUNNEL_URL"
        title="Book a free trial"
        scrolling="no"
        style="width:100%;border:0;display:block;min-height:720px"></iframe>
<script>
  window.addEventListener('message', function(e){
    if (e.data && e.data.ppFunnel === 'height'){
      var f = document.getElementById('ppFunnel');
      if (f) f.style.height = e.data.h + 'px';
    }
  });
</script>
The funnel sends its height to the page, and that little script resizes the frame to match — so it always fits, on desktop and mobile.
Step 3

Where to paste it — by platform

W Wix

  1. Editor → Add (+) → Embed Code → Embed HTML.
  2. Choose Code and paste the snippet (Method A) — or the whole funnel file (Method B, no hosting needed).
  3. Drag it full-width. Set the box height in the editor: about 900px desktop and 1250px mobile (Wix embeds don't auto-grow, so give it room).
  4. Preview to test.
⚠ Wix boxes-in embeds at a fixed height, so on Wix set a generous height by hand rather than relying on auto-resize.

S Squarespace

  1. Edit the page → Add Block → Code (or Embed).
  2. Paste the Method A snippet. Save.
  3. That's it — it auto-resizes on its own here.
Auto-resize works natively on Squarespace — no manual height needed.

W WordPress

  1. Edit the page → add a Custom HTML block.
  2. Paste the Method A snippet (or the whole file for Method B). Update.
  3. Auto-resizes on its own.
